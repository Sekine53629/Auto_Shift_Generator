# Auto Shift Generator

薬局のシフト表を Excel 上で作成する VBA マクロ一式です。

医師の診療数から日ごとの必要人数を割り出し、希望休・固定曜日・週N日・月間休日数といった
個人の条件を守りながら、**出勤と公休を自動で配置**します。手で直したいところは
パレットのクリックとスタンプで入力でき、変更はログに残るのでまとめて巻き戻せます。

```
        8/3   8/4   8/5   8/6   8/7   8/8
医師数    4     5     4     5     3     3     ← 日ごとの必要人数の元
金岡      ○     ▲     ●     公休   ▲     ○
石毛      ▲     ●     公休   ▲     ○     公休
早川      公休   ○     ▲     ●     公休   ▲
薬剤師数   5     6     5     6     4     4
過不足     0     0     0     0     0     0     ← 医師数 + n を満たしているか
```

## できること

| 機能 | 入口マクロ |
|---|---|
| シフトの自動作成 | `シフト自動作成` |
| クリック／スタンプ入力 | シート上のパレット（マクロ登録不要） |
| 直前の自動作成を巻き戻す | `シフト変更を戻す` |
| 印刷用に切り出して出力（PDF / Excel） | `ShiftExport_シフト表出力` |
| シートの初期設定（パレット・数式・名前付き範囲） | `ShiftSetup_初期設定実行` |
| 不足シートの生成（設定 / 祝日 / 変更ログ） | `ShiftSchema_不足シート生成` |
| 祝日マスタを内閣府 CSV から取り込む | `ShiftSchema_祝日マスタ取込` |
| 設定の整合性チェック | `シフト設定チェック` / `ShiftAuto_事前診断` |
| シート構造の調査（読み取り専用） | `ShiftSurvey_シート構造調査` |

## 導入

1. シフト表のブックを **`.xlsm`（Excel マクロ有効ブック）** で保存する
2. `Alt` + `F11` で VBE を開く
3. ［ファイル］→［ファイルのインポート］で **`dist/` の `*_sjis.bas` 10本すべて** を読み込む
   （依存関係があるため、一部だけでは動きません）
4. シフト表のシート見出しを右クリック →［コードの表示］で開き、
   **`dist/Sheet1_sjis.txt`** の全文を貼り付ける
5. Excel に戻り `Alt` + `F8` → **`ShiftSetup_初期設定実行`** を実行

手順の詳細とつまずきどころは **[docs/SETUP-ja.md](docs/SETUP-ja.md)**、
日々の運用は **[docs/manual.html](docs/manual.html)** を参照してください。

## 自動作成の流れ

```
既存入力の分類 … 入力済みのセルはすべて保持し、空白セルだけを埋める
      ↓
ルール適用 …… 固定曜日 / 週N日 / 手動(派遣) / 通常
      ↓
公休の配置 …… 週の基本休 → 余剰は連休化 → 残ノルマ → 連勤緩和
      ↓
CoverBalance … 日別の過不足を均す。余裕のある日の出勤を不足日へ移す
      ↓
FiveBalance … 混雑日(医師5名)の出勤回数を個人間で均す
      ↓
記号の割当 …… ○(早番) → ▲(遅番) → 残りを ● ▲ で均等 → 個人差を均す
      ↓
書き込み …… 差分をログに残しながらシートへ
```

**個人の休日数は工程をまたいでも変わりません。** `CoverBalance` も `FiveBalance` も
出勤日と公休日を1対1で入れ替えるだけなので、月間の休日数は公休の配置で決まった値のまま保たれます。

## 設定

`自動作成設定` シートの2か所で決まります。マクロ側にハードコードした値はありません。

**メンバー表（A〜I列）** — 1人1行

| 列 | 内容 |
|---|---|
| 氏名 | シフト表のA列と一致させる（照合キー） |
| 区分 | `薬剤師` / `事務員` |
| 休業 | `○` で当月スキップ（行が灰色になる） |
| 勤務ルール | `通常` / `固定曜日` / `週N日` / `手動` |
| 固定曜日 | 例 `月火金土`（勤務ルールが `固定曜日` のとき） |
| 週勤務日数 | 週N日ルールの N |
| 月間休日数 | 空欄なら土日祝と同数。**`通常` のときだけ読まれます** |
| 遅番・遅半 可否 | `不可` にすると ▲ を割り当てない |

**全体設定（K〜L列）**

| 設定 | 既定 |
|---|---|
| 早番(○) 人数/日 | 1 |
| 遅番(▲) 最低人数/日 | 3 |
| 連勤の上限（日） | 3 |
| 連休の上限（日） | 3 |
| 週の基本休日数 | 2 |
| 必要出勤数（医師数 + n）の n | 1 |
| ノルマ外の休み記号 | `有休` |
| 事務員の2人目以降の記号 | `●` |
| 事務員の早番(○) 人数/日 | 1 |
| 混雑日（医師5名）の遅番(▲) 最低人数/日 | 0（＝通常と同じ） |
| 不足を埋めるときの連勤上限の上乗せ（日） | 0（＝上乗せなし） |

`ShiftSchema_自動作成設定生成` は**空欄のセルにしか書きません**。
新しい設定項目が増えたときに再実行しても、既存の値は消えません。

> **連勤上限の上乗せについて** — 必要人数に届かない日を埋めるためだけに連勤の上限を緩める設定です。
> 通常の公休配置と連勤緩和は上乗せなしの上限を守ります。労務上の例外なので既定は0で、
> 使ったときは結果ダイアログに「誰が何日連勤になったか」を必ず列挙します。

## リポジトリ構成

```
src/                 UTF-8 版（正。GitHub 上で読む・差分を見るのはこちら）
dist/                Shift-JIS 版（生成物。VBE へインポートするのはこちら）
tools/build_sjis.py  src/ から dist/ を生成
tools/check_vba.py   静的チェック（CI で実行）
docs/SETUP-ja.md     導入手順・トラブルシューティング
docs/manual.html     運用マニュアル（毎月の作業・設定の意味・困ったとき）
```

`src/` を編集したら、`dist/` を更新してからコミットしてください。

```bash
python3 tools/build_sjis.py          # 生成
python3 tools/build_sjis.py --check  # 差分があれば exit 1（CI 用）
python3 tools/check_vba.py           # 静的チェック
```

> **なぜ 2 つあるの？**
> VBE の［ファイルのインポート］は Shift-JIS を前提に読み込むため、UTF-8 のままだと
> 日本語コメントが文字化けします。一方 GitHub 上で読みやすいのは UTF-8 です。
> そのため `src/`（UTF-8・正）と `dist/`（Shift-JIS・生成物）を分けています。

## 静的チェック

Excel が無い環境でも編集するため、VBE でコンパイルする前に落ちる類のミスを
`tools/check_vba.py` が機械的に検出します。

```
 1. Function の中の Exit Sub (逆も)      7. どこにも定義が無い識別子
 2. Sub / Function の終端キーワード違い   8. 宣言セクションの外にある宣言
 3. 戻り値を代入していない Function       9. マニュアルの版表記の食い違い
 4. 無条件 Exit の後ろの到達不能コード   10. 版を上げ忘れたモジュール
 5. モジュール間で重複する Public 名     11. 組み込み名と衝突する変数名
 6. エラーハンドラの無いプロシージャ     12. プロシージャ内で重複する行番号
```

検査 8〜12 は、いずれも実際に混入したミスを受けて追加したものです。

## 既知の制限

- **`Ctrl` + `Z` で元に戻せません。** VBA でセルを書き換えると Excel の取り消し履歴が消えるためです。
  自動作成の結果は `シフト変更を戻す` でセッション単位に巻き戻せます。
  手入力の押し間違いは、パレットの右クリックで1つ戻してください
- **人日そのものが足りない月は、必要人数を満たせません。** 総必要人日が総出勤人日を上回っている場合、
  配置をどう変えても不足は消えません。結果ダイアログに両方の数字を出すので、
  「配分の偏り」なのか「人手不足」なのかはそこで判別できます
- シフト範囲内では右クリックメニューが出ません（逆順操作に割り当てているため）。
  必要なときはパレットの `OFF` でマクロを止めてください
- 祝日マスタの Power Query 取り込みは Excel 2016 以降が必要です。
  それ以前では CSV を手で貼る運用になります
