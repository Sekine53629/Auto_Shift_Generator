# excel-shift-click-input

Excel のシフト表で、セルを**ダブルクリック**するだけで
`空白 → ◯ → ● → ▲ → 公休 → 希休 → 空白` と入力を切り替える VBA マクロです。
シート上の「パレット」から記号を選んで、スタンプのように押していく使い方もできます。

```
   C     D     E     F                    AI  AJ      AK
5  ◯    ●     公休  ▲       …                パレット
6  ●    ▲     ◯    希休     …                OFF        マクロを止める
7  公休  ◯    ●     ◯       …            ★  連続切替    ダブルクリックで順に切替
                                              色クリア   背景色だけ消す
   ↑ ダブルクリックで切替                                消去（空白にする）
     右クリックで1つ戻る                          ◯
                                                  ●
                                                  ▲
                                                  公休
                                                  希休
                                                  ◯       ◯（緑）  ← 背景色ごとスタンプ
                                                  ●       ●（緑）
```

## 特長

- **誤操作しない** — 値が変わるのはダブルクリックと右クリックのときだけ。カーソル移動のクリックでは変わりません
- **逆順に戻せる** — 行き過ぎたら右クリックで 1 つ前へ
- **色つき記号もパレットで完結** — スタンプはパレットのセルの文字色・背景色をそのままコピーします。
  「緑地の ◯」を作るのに専用のコードは不要で、パレットのセルを緑に塗るだけ。青地・黄色地も同様に増やせます
- **範囲まとめ入力** — スタンプモードで範囲を選んで右クリックすると、選択範囲に一括で入力されます
- **記号は自由** — `CycleValues` の配列を書き換えれば 5 〜 7 種類でも何種類でも

## 導入

1. シフト表のブックを **`.xlsm`（Excel マクロ有効ブック）** で保存する
2. `Alt` + `F11` で VBE を開く
3. ［ファイル］→［ファイルのインポート］で **`dist/ShiftClick_sjis.bas`** を読み込む
   （コピー＆ペーストで入れる場合は `src/ShiftClick.bas` の全文を標準モジュールへ）
4. シフト表のシート見出しを右クリック →［コードの表示］で開き、
   **`src/SheetModule.txt`** の全文を貼り付ける
5. Excel に戻り `Alt` + `F8` → **`ShiftClick_パレット作成`** を実行

詳しい手順とトラブルシューティングは **[docs/SETUP-ja.md](docs/SETUP-ja.md)** を参照してください。

## 操作

| 操作 | 動き |
|---|---|
| クリック（1回） | 何も起きない（カーソル移動だけ） |
| **ダブルクリック** | 次の記号へ |
| **右クリック** | 1 つ前の記号に戻る |
| パレットの記号をクリック | スタンプモードに切り替え |
| スタンプモードでダブルクリック | その記号を押す |
| スタンプモードで範囲選択 → 右クリック | 選択範囲にまとめて押す |

現在のモードは画面左下のステータスバーに表示されます。

## 設定

`src/ShiftClick.bas` の先頭にまとまっています。

| 定数 | 既定値 | 意味 |
|---|---|---|
| `SHIFT_RANGE` | `"C5:AG40"` | マクロが効く範囲 |
| `PALETTE_RANGE` | `"AJ4:AJ14"` | パレットの位置（縦 1 列・11 行） |
| `CYCLE_TRIGGER` | `"double"` | 切替の操作。`"single"` でシングルクリックにも反応 |
| `STAMP_TRIGGER` | `"double"` | スタンプの操作。同上 |
| `APPLY_FILL` | `True` | スタンプ時にパレットの背景色も反映 |
| `CYCLE_RESETS_FILL` | `False` | `True` で切替のたびに背景色をクリア |
| `MOVE_AFTER` | `""` | `"down"` で入力後にカーソルを 1 つ下へ |
| `SKIP_FORMULA_CELLS` | `True` | 数式入りセルは書き換えない |

切り替わる記号の順番：

```vba
Private Function CycleValues() As Variant
    CycleValues = Array("", "◯", "●", "▲", "公休", "希休")
End Function
```

## マクロ一覧（`Alt` + `F8`）

| マクロ名 | 内容 |
|---|---|
| `ShiftClick_パレット作成` | パレットをシート上に作る（初回に 1 度） |
| `ShiftClick_選択範囲にスタンプ` | 選択範囲に現在のスタンプを一括入力 |
| `ShiftClick_連続切替に戻す` | スタンプモードを解除 |
| `ShiftClick_セルフチェック` | 設定が正しく読み込まれているか確認 |

## リポジトリ構成

```
src/                UTF-8 版（GitHub 上で読む・差分を見るのはこちら）
  ShiftClick.bas      標準モジュール
  SheetModule.txt     シートモジュール（イベント 3 つ）
dist/               Shift-JIS 版（VBE へインポートするのはこちら）
tools/build_sjis.py src/ から dist/ を生成するスクリプト
docs/SETUP-ja.md    導入手順・トラブルシューティング
```

`src/` を編集したら、次を実行して `dist/` を更新してからコミットしてください。

```bash
python3 tools/build_sjis.py
```

> **なぜ 2 つあるの？**
> VBE の［ファイルのインポート］は Shift-JIS を前提に読み込むため、UTF-8 のままだと
> 日本語コメントが文字化けします。一方 GitHub 上で読みやすいのは UTF-8 です。
> そのため `src/`（UTF-8・正）と `dist/`（Shift-JIS・生成物）を分けています。

## 既知の制限

- **`Ctrl` + `Z` で元に戻せません。** VBA でセルを書き換えると Excel の取り消し履歴が消えるためです。
  押し間違えたときは右クリックで 1 つ戻すか、正しい値を入れ直してください
- **「1 回目は移動、2 回目のシングルクリックで変更」は実装できません。**
  Excel は、すでに選択されているセルをもう一度シングルクリックしてもイベントを発生させないためです。
  代わりにダブルクリック方式を採用しています
- シフト範囲内では右クリックメニューが出ません（逆順操作に割り当てているため）。
  必要なときはパレットの「OFF」でマクロを止めてください
