# シフト表 クリック入力マクロ 導入手順（v3）

セルを**ダブルクリック**すると **空白 → ◯ → ● → ▲ → 公休 → 希休 → 空白** と順に切り替わります。
さらに、パレットから記号を選んで「スタンプ」のように押す使い方もできます。

> **v3 での変更点：セルを選ぶだけのクリックでは値が変わらなくなりました。**
> 値が変わるのは「ダブルクリック」と「右クリック」のときだけです。

---

## 1. 導入（5分）

### ① ファイルを .xlsm で保存する
シフト表のブックを開き、**［ファイル］→［名前を付けて保存］→ ファイルの種類を「Excel マクロ有効ブック (*.xlsm)」** にして保存します。
（.xlsx のままだとマクロが保存されません）

### ② VBE を開く
`Alt` + `F11` を押します。

### ③ 標準モジュールを取り込む
VBE のメニューで **［ファイル］→［ファイルのインポート］** を選び、
`ShiftClick_標準モジュール.bas` を指定します。

> インポートがうまくいかない場合は、［挿入］→［標準モジュール］で空のモジュールを作り、
> **`ShiftClick_標準モジュール_貼り付け用.txt`** の中身を全部コピーして貼り付けてください。
> （`.bas` の中身を直接コピペすると、1行目の `Attribute VB_Name = ...` が原因で
> 「プロシージャの外では無効です」というエラーになります。貼り付け用ファイルはこの行を除いてあります）

### ④ シートモジュールに貼り付ける
VBE 左上のツリーから **シフト表のシート名** をダブルクリックして開き、
`ShiftClick_シートモジュール.txt` の中身を **そのまま貼り付け** ます。
（ここは標準モジュールではなく、必ず「シートの」コード画面です）

### ⑤ パレットを作る
Excel に戻り、シフト表のシートを開いた状態で `Alt` + `F8` →
**`ShiftClick_パレット作成`** を実行します。
AI〜AK 列あたりにパレットが自動で作られます。

これで完成です。

---

## 2. 使い方

| 操作 | 動き |
|---|---|
| シフト欄をクリック（1回） | **何も起きません**（カーソル移動だけ） |
| シフト欄を**ダブルクリック** | 次の記号へ（空白→◯→●→▲→公休→希休→空白） |
| シフト欄を**右クリック** | 1つ前の記号に戻る |
| パレットの記号をクリック | その記号の「スタンプモード」になる |
| スタンプモードでダブルクリック | その記号を押す |
| スタンプモードで範囲選択→右クリック | 選んだ範囲にまとめて押す |
| パレットの「連続切替」をクリック | 通常の切替に戻る |
| パレットの「OFF」をクリック | マクロを一時停止（普通のExcel操作に戻る） |

現在どのモードかは、画面左下の **ステータスバー** に表示されます。

### シングルクリックで動かしたい場合

標準モジュール先頭の設定を書き換えるだけで戻せます。

```vba
Public Const CYCLE_TRIGGER As String = "single"   ' 連続切替をシングルクリックに
Public Const STAMP_TRIGGER As String = "single"   ' スタンプをシングルクリックに
```

`"double"`（既定）＝ダブルクリックのみ、`"single"` ＝シングルクリックでも反応。
連続切替とスタンプで別々に設定できます（例：切替はダブル、スタンプはシングル）。

> **なぜ「1回目は移動、2回目のシングルクリックで変更」にできないの？**
> Excel は、すでに選択されているセルをもう一度シングルクリックしても
> イベントを発生させない仕様のため、マクロ側でその2回目を検知できません。
> そのため「ダブルクリックのみ」が、誤操作を防ぐ確実な方法になります。

## 3. パレットの中身（初期状態）

| 位置 | 内容 | 役割 |
|---|---|---|
| 1 | OFF | マクロを止める |
| 2 | 連続切替 | ダブルクリックで順に切替（既定） |
| 3 | 色クリア | 背景色だけ消す |
| 4 | （空白） | 消去（セルを空白にする） |
| 5〜9 | ◯ ● ▲ 公休 希休 | 通常のスタンプ |
| 10〜11 | ◯ ●（緑地） | 緑地バージョン |

**ポイント：スタンプはパレットのセルの見た目をそのままコピーします。**
つまり「緑地の◯」を別のマクロで作る必要はなく、
パレットのセルを緑に塗っておけば、それを押すだけで緑地の◯が入ります。
青地・黄色地などを増やしたいときは、**パレットの空きセルに記号を書いて好きな色に塗るだけ** です。
（パレットのセルは右クリックすると通常のメニューが出るので、そのまま書式設定できます）

パレットの行数を増やしたい場合は、標準モジュール冒頭の
`PALETTE_RANGE`（既定 `"AJ4:AJ14"`）を広げてください。

## 4. よく変えたい設定

標準モジュールの先頭にまとまっています。

| 定数 | 既定値 | 意味 |
|---|---|---|
| `SHIFT_RANGE` | `"C5:AG40"` | クリックが効く範囲 |
| `PALETTE_RANGE` | `"AJ4:AJ14"` | パレットの位置 |
| `CycleValues` | `"", ◯, ●, ▲, 公休, 希休` | 切り替わる順番。ここを書き換えれば5〜7種類でも自由 |
| `APPLY_FILL` | `True` | スタンプ時にパレットの背景色も反映する |
| `CYCLE_RESETS_FILL` | `False` | `True` にすると連続切替のたびに背景色を消す |
| `MOVE_AFTER` | `""` | `"down"` にすると入力後にカーソルが1つ下へ動く |
| `SKIP_FORMULA_CELLS` | `True` | 数式入りセルは書き換えない |
| `CYCLE_TRIGGER` | `"double"` | 切替の操作。`"single"` でシングルクリックにも反応 |
| `STAMP_TRIGGER` | `"double"` | スタンプの操作。同上 |

例）7種類にしたい場合：

```vba
CycleValues = Array("", "◯", "●", "▲", "△", "公休", "希休", "有休")
```

## 5. 注意点

- **マクロで書き換えた内容は `Ctrl` + `Z` で元に戻せません。**（VBAの仕様）
  押し間違えたときは右クリックで1つ戻すか、その場で正しい値をクリックし直してください。
- 土日の色分けは **条件付き書式** で設定しておくと、スタンプで塗りつぶしても消えません。
  （手動の塗りつぶしは、色付きスタンプを押すと上書きされます）
- シートを保護している場合、パレットの★印を書き込む列（既定 AI 列）と
  シフト入力欄のロックを外しておいてください。
- ファイルを開いたときに「マクロが無効にされました」と出たら、
  黄色いバーの［コンテンツの有効化］をクリックしてください。
- パレットを印刷したくない場合は、印刷範囲を設定するか、パレットの列を非表示にしてください。
  （列を非表示にしてもマクロは動きます）

## 6. うまく動かないとき

| 症状 | 対処 |
|---|---|
| クリックしても何も起きない | v3 は**ダブルクリック**で動きます。それでも動かない場合はパレットが「OFF」になっていないか、シートモジュールに貼り忘れていないかを確認 |
| `変数が定義されていません` | 標準モジュールのインポートがされていない（手順③をやり直す） |
| 文字化けする | 貼り付け用の UTF8版と Shift-JIS版を入れ替えて試す |
| `プロシージャの外では無効です` | ①`.bas` の中身をコピペした場合 → 1行目の `Attribute VB_Name = ...` を削除するか、貼り付け用ファイルを使う ②コードの一部だけを貼った場合 → モジュールの中身を全選択して消し、全文を貼り直す |
| 右クリックメニューが出ない | シフト範囲内では意図的に抑止しています。パレット上や範囲外では通常どおり出ます |

## 7. 便利な追加ワザ

`Alt` + `F8` から実行できるマクロ：

| マクロ名 | 内容 |
|---|---|
| `ShiftClick_パレット作成` | パレットを作り直す |
| `ShiftClick_選択範囲にスタンプ` | 選んだ範囲に現在のスタンプをまとめて押す |
| `ShiftClick_連続切替に戻す` | スタンプモードを解除 |
| `ShiftClick_セルフチェック` | 設定が正しく入っているか確認 |

`ShiftClick_選択範囲にスタンプ` は、［開発］→［マクロ］→［オプション］から
`Ctrl` + `Shift` + `S` などのショートカットキーに割り当てておくと快適です。
