# 導入手順

シフト表のブックにマクロを入れて、使える状態にするまでの手順です。
日々の運用（毎月の作業・設定の意味・困ったとき）は **[manual.html](manual.html)** を参照してください。

---

## 1. 導入（10分）

### ① ファイルを .xlsm で保存する

シフト表のブックを開き、**［ファイル］→［名前を付けて保存］→ ファイルの種類を
「Excel マクロ有効ブック (*.xlsm)」** にして保存します。
`.xlsx` のままだとマクロが保存されません。

### ② VBE を開く

`Alt` + `F11` を押します。

### ③ 標準モジュールを取り込む（10本すべて）

VBE のメニューで **［ファイル］→［ファイルのインポート］** を選び、
`dist/` の `*_sjis.bas` を **10本すべて** 読み込みます。

```
AutoShiftGenerator_sjis.bas   ShiftClick_sjis.bas     ShiftSchema_sjis.bas
ErrorLogger_sjis.bas          ShiftCommon_sjis.bas    ShiftSetup_sjis.bas
ShiftAutoLog_sjis.bas         ShiftExport_sjis.bas    ShiftSurvey_sjis.bas
ShiftAutoPlace_sjis.bas
```

**一部だけでは動きません。** モジュール間に依存関係があり、`ShiftCommon` の定数は
ほぼ全モジュールが参照しています。

> `src/` の UTF-8 版を直接コピペしないでください。VBE は Shift-JIS を前提に読むため、
> 日本語コメントが文字化けします。GitHub 上で中身を読むのが `src/`、
> VBE に入れるのが `dist/` です。

### ④ シートモジュールに貼り付ける

VBE 左上のツリーから **シフト表のシート名** をダブルクリックして開き、
`dist/Sheet1_sjis.txt` の中身を **そのまま貼り付け** ます。

ここは標準モジュールではなく、必ず「シートの」コード画面です。
このファイルだけ `.bas` ではなく `.txt` なのは、シートモジュールは
［ファイルのインポート］で取り込めないためです。

### ⑤ 初期設定を実行する

Excel に戻り、シフト表のシートを開いた状態で `Alt` + `F8` →
**`ShiftSetup_初期設定実行`** を実行します。

1回の実行で次がすべて行われます。

| 工程 | 内容 |
|---|---|
| 不足シートの生成 | `自動作成設定` / `祝日マスタ` / `シフト変更ログ` が無ければ作る |
| パレットの生成 | 日付行の上に3行（★ / 本体 / ラベル）を確保して作る |
| ヘッダの数式 | 年月セル・祝日サマリー |
| 集計行の数式 | 医師数（診）／薬剤師出勤数／過不足 |
| 集計列の数式 | 公休・有休・○早番・▲遅番・●遅半・5診出勤（AH〜AM） |
| 名前付き範囲 | `シフト入力範囲` ほか4つを動的数式で定義し直す |

パレット用の3行が無い場合は自動で挿入されます。白紙のブックからでも作れます。
**既にパレットがある場合は挿入しません**（実行のたびに行が増えないようにしてあります）。

### ⑥ 設定シートを埋める

`自動作成設定` シートに、氏名・区分・勤務ルールを入力します。
氏名は**シフト表のA列と一字一句同じ**にしてください。照合キーになります。

自動生成された時点では全員が `薬剤師` / `通常` / 遅番可 になっています。
事務員・固定曜日・週N日・手動（派遣）・休業・遅番不可 は手で設定します。

### ⑦ 祝日マスタを取り込む

`Alt` + `F8` → **`ShiftSchema_祝日マスタ取込`** を実行すると、
内閣府が公開している「国民の祝日」CSV を取り込みます。
以後は表の中で右クリック →［更新］で最新にできます。

- 実行前に必ず確認ダイアログが出ます（インターネットに接続するため）
- Excel 2016 以降が必要です。それ以前では CSV を `祝日マスタ` の A/B 列に手で貼ってください
- 手貼りの運用も従来どおり使えます

これで完成です。`シフト自動作成` が実行できる状態になりました。

## 2. 動作確認

`Alt` + `F8` → **`ShiftAuto_事前診断`** を実行すると、
自動作成に必要な前提がそろっているかを一覧で確認できます。

**`シフト設定チェック`** は設定シート側の整合性（氏名の重複、区分の異常値、
シフト表に無い氏名など）を確認します。

`シフト自動作成` を実行すると、問題があれば実行前に確認ダイアログが出ます。

```
設定の整合性に注意点があります。

■ マスタにあるがシフト表に無い(行削除・氏名変更?)
・田中

このまま実行しますか?
```

## 3. うまく動かないとき

| 症状 | 対処 |
|---|---|
| `変数が定義されていません` | モジュールの取り込み漏れ。10本すべて入っているか確認（特に `ShiftCommon`） |
| `プロシージャの外では無効です` | `.bas` の中身を手でコピペした場合、1行目の `Attribute VB_Name = ...` が原因。［ファイルのインポート］を使う |
| `Ambiguous name detected` | 同じモジュールを2回インポートしている。VBE のツリーで重複を消す |
| 日本語コメントが文字化けする | `src/`（UTF-8）を入れてしまっている。`dist/`（Shift-JIS）を使う |
| クリックしても何も起きない | ①パレットが `OFF` になっていないか ②シートモジュールの貼り忘れ ③値が変わるのは**ダブルクリック**と右クリックのときだけ |
| `シフト入力欄を特定できません` | B列の開始日の数式、またはA列の `備考` `医師名` ラベルを確認。`ShiftSurvey_シート構造調査` で行構成を書き出せる |
| `対象月の日付が見つかりません` | 年月行のA列に年月が入っているか確認 |
| 右クリックメニューが出ない | シフト範囲内では意図的に抑止しています。パレット上や範囲外では通常どおり出ます |
| マクロが無効にされました | 黄色いバーの［コンテンツの有効化］をクリック |

**エラーの詳細は `C:\VBAErrorLogs\ErrorLog_YYYYMMDD.csv` に残ります。**
どのモジュールの、どのプロシージャの、何行目で、どんな変数の状態だったかが記録されます。
正常終了も記録されるので、実行できたかどうかの確認にも使えます。

## 4. シートの構成について

マクロはシート上の位置を**ラベルから逆算**します。行を増減しても追随しますが、
次のラベルは動かさないでください。

| A列のラベル | 役割 |
|---|---|
| `シフトパレット` | パレット本体の行 |
| `備考` | 入力欄の下端を決める基準 |
| `医師名` | 医師名欄の位置 |
| `医師数(診)` | 集計行の先頭 |

年月は A列の年月行、日付は B列の開始日の数式が基準です。

構成が想定と合わなくなったら **`ShiftSurvey_シート構造調査`** を実行してください。
行構成・数式・名前付き範囲を読み取り専用でレポートに書き出します。

## 5. 更新するとき

新しい版のモジュールに入れ替える手順です。

1. VBE で古いモジュールを右クリック →［○○の解放］→ 保存せずに削除
2. `dist/` から新しい `*_sjis.bas` をインポート
3. **`ShiftSetup_初期設定実行`** を1回実行
   （集計列の数式と見出しが新しい版に貼り直されます。設定シートは
   空欄のセルにしか書かないので、既存の設定値は消えません）

完了ダイアログの最後に **「既定値と異なる全体設定」** が出ることがあります。
設定シートの全体設定（K/L列）は空欄のときしか書き込まれないため、版が上がって
既定値が変わってもブック側は古いまま残ります。身に覚えのない項目があれば、
新しい既定値が届いていないということなので手で直してください。
値はマクロが勝手に書き換えることはありません。

> **集計列を参照している数式や別シートがある場合は要注意です。**
> ShiftSetup v3.2 で集計列の並びが
> `休 / ○早番 / ▲遅番 / ●遅半 / 5診出勤` から
> `公休 / 有休 / ○早番 / ▲遅番 / ●遅半 / 5診出勤` に変わり、
> **AH〜AL の意味が1つずつずれています。** マクロは集計列そのものは直しますが、
> 他シートからの参照までは追えないので、貼り直してください。

シートモジュール（`Sheet1`）は削除できないので、コード画面を全選択して消してから
新しい `Sheet1_sjis.txt` を貼り直してください。
